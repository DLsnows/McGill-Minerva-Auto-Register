# P7c — Web i18n / 语言切换设计（zh / en / fr）

> 设计日期：2026-06-02 · 阶段：P7c（P7 Web UI 的增量）· 依赖：P7a+P7b（已合并）

## 1. 目标

为 Synapse Web 前端加入语言切换，支持 **中文（zh）/ English（en）/ Français（fr）**。
McGill 位于魁北克，法语为合理需求。用户可在顶部栏即时切换，选择被记住。

## 2. 技术选型

- **`i18next` + `react-i18next`**：通过 `initReactI18next` 初始化一个全局 i18n 实例
  （`packages/web/src/i18n/index.ts`），副作用式初始化；`main.tsx` 与测试 setup 均导入它，
  组件用 `useTranslation()` 的 `t()` 取文案，无需手动包 Provider。
- **不引入 language-detector 包**（YAGNI / 少依赖）：初始语言用手写检测 —
  `localStorage['lang']` → `navigator.language` 前缀（`zh`/`fr`/`en`）→ 回退 `en`。
  切换时写回 `localStorage['lang']`。
- 新增依赖：`i18next`、`react-i18next`（web 包）。

## 3. 语言与默认

- 语言：`zh`（中文）、`en`（English）、`fr`（Français）。
- **默认**：浏览器语言自动选择，识别不出回退 `en`（用户已确认）。
- 法语翻译由实现者撰写。

## 4. 翻译范围

- **翻译（静态界面 chrome）**：导航胶囊、数据跑马灯标签、按钮、页面标题、表单字段标签、
  状态徽章（watching/waitlisted/registered/paused/stopped/error 的显示文案）、空态、
  横幅、Session 文案、Settings/Courses 全部静态文字、控制台标题栏（“live stream / reconnecting”）。
- **不翻译（本期，用户已确认）**：实时控制台的**日志内容** —— 这些是后端实时推送的
  `LogEvent.message`（自由文本，英文）。翻译它们需后端消息键化，超出本期范围。
  控制台日志保持英文。课程数据本身（课程名/CRN/term）也不翻译（来自 Minerva）。

## 5. 组件 / 数据流

- **`i18n/index.ts`**：定义 `resources = { en, zh, fr }`（每语言一份扁平 key→文案字典），
  `detectInitialLang()`，`i18n.use(initReactI18next).init({ resources, lng, fallbackLng: 'en',
  interpolation: { escapeValue: false } })`。导出 `setLang(lng)`（切换 + 写 localStorage）。
- **`components/LanguageSwitcher.tsx`**：顶部栏分段控件 `中文 | EN | FR`，高亮当前语言，
  点击调用 `setLang`。放在 `App.tsx` 的 top bar **NavPills 右侧**（同一行 flex 容器，
  `Synapse … NavPills | LanguageSwitcher`）。
- **各组件/页面**：把硬编码英文替换为 `t('key')`。状态徽章用 `t('status.' + status)`。
- **key 命名**：按区域分组，如 `nav.dashboard`、`ticker.watching`、`dashboard.watchedCourses`、
  `courses.addCourse`、`settings.pollInterval`、`session.openAndLogin`、`status.watching` 等。

## 6. 低改动策略（保护现有测试）

- **英文译文 = 当前已有英文原文**（逐字一致）。测试环境 i18n 默认 `en`（jsdom 无 localStorage、
  `navigator.language` 通常 en），渲染出的字符串与现状一致 → 现有 123 个测试基本无需改动
  （含 `getByLabelText` 的表单标签、按钮名、空态文案等）。
- 测试 setup 导入 i18n 模块以保证初始化；必要时在 setup 里强制 `i18n.changeLanguage('en')` 确保确定性。

## 7. 错误处理 / 边界

- 缺失 key → i18next 回退 `fallbackLng: 'en'`，再缺失则显示 key 本身（开发期可见）。
- localStorage 不可用（隐私模式）→ 读写包 try/catch，降级为仅内存（当次会话有效）。
- 切换语言即时重渲染（react-i18next 订阅 languageChanged 事件）。

## 8. 测试（Vitest + RTL）

- `i18n`：`detectInitialLang` 各分支；`setLang` 写 localStorage + 改变 `t()` 输出。
- `LanguageSwitcher`：渲染三选项、高亮当前、点击切换调用 setLang/语言变化。
- 切换效果：渲染某组件，切到 zh，断言文案变为中文。
- 现有页面/组件测试：保持绿（英文默认）。

## 9. 非目标

- 后端日志/通知消息的本地化（控制台日志、邮件/桌面通知文案保持英文）。
- Minerva 课程数据翻译。
- 复数/日期本地化等高级 i18n 特性（YAGNI；当前文案无需）。
- RTL 语言（zh/en/fr 均 LTR）。
